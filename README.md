Aplicação web desenvolvida com o objetivo de simular um **SaaS de agendamento de consultas médicas**, conectando pacientes a profissionais e clínicas em um único lugar.

> ⚠️ Este projeto foi desenvolvido durante um bootcamp, sendo meu **primeiro contato com a construção completa de um SaaS (frontend + backend + banco de dados)**.

---

## 🚀 Sobre o projeto

O **Doutor Agenda** é uma aplicação que busca simular um produto real, permitindo:

- Agendamento de consultas médicas  
- Cadastro e autenticação de usuários  
- Visualização de serviços e especialidades  
- Estrutura pensada para escalar como SaaS  

Além disso, criei uma **Landing Page** para melhor experiência:

- Apresentar o produto  
- Explicar a proposta da plataforma  
- Direcionar o usuário para a autenticação e uso do sistema  

---

## 🔐 Autenticação

O sistema conta com:

- Login tradicional (email/senha)  
- **Login com Google (OAuth)**  

Isso simula um cenário real de aplicação moderna, facilitando o acesso do usuário.

---

## 💳 Integração com pagamentos

Foi iniciada a integração com o **Stripe**, com o objetivo de simular um modelo SaaS.

- A estrutura básica foi implementada  
- **O fluxo de pagamento ainda não está completo**  
- Não há processamento real de cobranças no momento  

> Essa parte foi incluída com foco em aprendizado e entendimento da arquitetura, não como solução final de produção.

## 🧠 Contexto de aprendizado

Este projeto foi construído durante um bootcamp intensivo.

- Não domino totalmente todas as tecnologias utilizadas  
- O foco foi entender o funcionamento de uma aplicação completa
